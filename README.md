# OX Inventory V2 Reskin

This repository contains a custom reskin of the **ox_inventory** for FiveM, featuring an enhanced interface and a seamlessly integrated clothing menu. The goal of this reskin is to provide a more visually appealing and user-friendly experience while maintaining the functionality and flexibility of the original **ox_inventory**.

## Features

### Modern Interface
- **Redesigned layout** for a clean, game‑ready look that fits both casual and roleplay servers.
- Clear **visual hierarchy** and **improved iconography** for *faster item recognition and interaction*.
- Responsive panel system that **adapts** to different resolutions and aspect ratios.
- Smooth UI transitions and micro‑animations powered by **Framer Motion**, without over-the-top effects.

### Integrated Clothing System
- A built-in clothing menu, allowing players to **change their outfits** directly from the inventory screen.
- Fast and easy access to clothing with intuitive navigation between categories (hats, shoes, accessories, etc.).
- Completely **synced with the server** to ensure no delays in character customization.

### Technology Stack (UI)

- **React** for the NUI component structure and state management.
- **TypeScript** for safer, more maintainable front‑end code.
- **Framer Motion** for subtle, performant transitions and animations.
- **Lucide React** for sharp, consistent iconography across the interface.
- **TailwindCSS** for fine‑grained styling, theming, and layout control.
